# Models

SQLModel ORM entities. All use `TimeStampMixin`. Project-scoped models use `ProjectScopeMixin` (injects `project_id: int` FK → `project.id` CASCADE). Schemas must NOT import models (one-way dependency: models → schemas).

## Structure

```
models/
├── project.py          # Project (root entity)
├── task.py             # Task, TaskDependency
├── resource.py         # Resource
├── resource_public.py  # ResourcePublic (global dictionary, no project_id)
├── daily_report.py     # ImportBatch (UUID PK)
├── resource_usage.py   # TaskResourceUsage, ManualSubmissionBatch
├── optimize.py         # OptimizationRun, ParetoSolution, ResourceConstraint
├── tag.py              # Tag(flat+group), ResourceTag, TaskTag, UsageTag
├── chart.py            # ChartDefinition (no slice_entity/resource_categories)
├── slice.py            # ChartSlice, SliceTagMapping (or/and groups; negative builtin tag ids)
├── usage_snapshot.py   # usage_snapshot 物化视图说明（非 ORM 表，见 alembic）
├── mixin.py            # TimeStampMixin, ProjectScopeMixin, SoftDeleteMixin
├── pydantic_json.py    # PydanticJson utility (stores Pydantic models in JSON columns)
```

## Notable Patterns

- Models can depend on schemas (e.g., `Task` uses `TaskBase` fields, `Resource` uses `ResourceCreate` fields) — reverse is forbidden. See the root `AGENTS.md` for the required/default/nullability rules and PUT partial-update semantics.
- Update schemas must keep fields optional to provide, reject explicit `null` for NOT NULL columns, and PUT handlers must use `model_dump(exclude_unset=True)`.
- `ImportBatch` uses `UUID` PK with server_default `gen_random_uuid()` (different from other models)
- `PydanticJson` in `pydantic_json.py` stores Pydantic model instances as JSON in `sa.Column(sa.JSON)`
- `TaskDependency` has a composite PK (`task_id`, `predecessor_id`) with CHECK `task_id != predecessor_id`
- `UsageType` is a PostgreSQL native ENUM (via `StrEnum` + alembic-postgresql-enum)
- `ResourceCategory` and `DependencyType` enums live in schemas, referenced by models via `PydanticJson`
- `SoftDeleteMixin` exists but is currently unused by any table
