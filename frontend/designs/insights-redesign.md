# 分析洞察页改造设计

> 状态：已确认（2026-08-20）· 对应后端任务清单见 §6

## 1. 背景与目标

“分析洞察”页按项目生命周期重构为三个阶段，覆盖碳排放功能的完整闭环：

| 阶段 | 回答的问题     | 产出                                 |
| ---- | -------------- | ------------------------------------ |
| 计划 | 怎么干最划算？ | 推荐施工策略 + 可执行施工计划        |
| 施工 | 正在怎么干？   | 实际进度 / 天气 / 实际碳排放与成本   |
| 评价 | 干得怎么样？   | 排放分布 / 计划践行度 / 低碳措施成效 |

## 2. 已确认决策

| #   | 决策         | 结论                                                                                                                                                               |
| --- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 水电建模     | 不新建资源类别。项目设置中指定水电资源（仿 `housing_resource_id` 模式），资源自带单一碳排放因子，后端聚合时把指定资源归入“水电”桶。水电使用量按普通 usage 记录录入 |
| 2   | 成本口径     | 所有成本统一为资源：分包、一次性费用也是资源（用量可记 1）。成本 = 用量 × 单价，成本类别与排放类别一致（含运输）                                                   |
| 3   | 计划践行度   | 由后端聚合接口一次算好（`GET /evaluation/compliance`），前端只渲染                                                                                                 |
| 4   | 工序进度     | 按日记录（日期 + 完成百分比），与工期粒度一致；进度到 100% 即判定完成，实际完成时间 = 达 100% 的那天                                                               |
| 5   | 进度录入位置 | 在日报处理流程中随每日资源用量一起录入；任务管理页保留单值快捷补录                                                                                                 |
| 6   | 天气         | 手动按月录入（降水 / 气温 / 光照），v1 纯展示，不做关联分析                                                                                                        |
| 7   | 评价排放分布 | 复用现有“碳排放图表”（标签切片饼图）体系；预置“排放类别”维度 + 种子标签 + 资源默认归类                                                                             |
| 8   | 低碳措施     | 记录“添加 / 替换设备”逻辑，节碳由后端自动计算（不手填）                                                                                                            |
| 9   | 方案落地     | 交互式“计划编制”工作台：选定方案 → 调整甘特图 → 录入措施 → 后端预估 → 保存为施工计划基线                                                                           |
| 10  | 甘特调整范围 | v1 仅允许：开始时间偏移 + 策略模式切换 + 工期微调（带依赖校验）；实际大概率只用开始偏移                                                                            |
| 11  | 临时用房     | 计划侧由 NSGA-II 按人数推导（`persons_per_room` × `housing_safety_factor`）；实际侧作为普通 usage 记录录入。评价分布的实际切片可正常打标，计划侧由计划基线数据承载 |
| 12  | 碳价         | 不需要。规划前提“碳排放因子及其估价”即 Resource 的 `carbonFactor` 与 `unitPrice`，已有                                                                             |

## 3. 页面结构

```
分析洞察
├─ 计划阶段
│  ├─ 优化结果      现有，基本保留（选定方案 → 进入计划编制）
│  ├─ 计划编制      NEW：方案落地工作台
│  └─ 策略比选      合并现有「方案对比」（雷达 ≤5 方案）与「施工模式对比」（双 run 合并），
│                   改造为“修改依赖 → 重跑 → 对比”引导
├─ 施工阶段
│  ├─ 施工进度      NEW：计划 vs 实际进度（甘特 / 时间线，来自按日进度记录）
│  ├─ 天气情况      NEW：月度录入 + 图表
│  └─ 碳排放与成本  现有碳排放分析增强：+水电桶、+成本卡片 / 月度成本趋势 / 成本 TopN
└─ 评价阶段
   ├─ 碳排放分布    复用标签图表系统（预置“排放类别”维度）
   ├─ 计划践行度    NEW：7 项计划 vs 实际对照
   └─ 低碳措施      NEW：措施清单 + 预估/实际节碳 + 状态
```

侧边栏需要小改造：子菜单支持阶段分组标题（计划阶段 / 施工阶段 / 评价阶段）。

数据录入位置保持不扩散：

- 实际资源使用量 → 现有「资源使用录入」+「日报处理」
- 工序进度 → 「日报处理」新增进度录入（按日）+「任务管理」快捷补录
- 天气 → 「分析洞察 / 天气情况」页内月度表格
- 水电资源指定 → 「项目概览 / 项目信息」（仿临时用房选择）

## 4. 核心数据模型

### 4.1 施工计划基线（plan）

计划编制的保存结果，评价阶段对比基准：

```text
Plan
├─ 来源优化解（可选关联 run_id / solution_id）
├─ 任务计划快照：task_id / 开始时间 / 工期 / 策略模式（普通/加速/低碳/双策略）
├─ 月度计划：月 / 各资源计划用量 / 成本 / 碳排放（含按人数推导的临时用房）
├─ 措施清单（见 4.5，状态=计划中）
└─ 汇总：总工期 / 总成本 / 总碳排
```

### 4.2 工序进度记录

```text
task_id / date / percent(0-100)
```

- 100% 即完成；实际完成时间 = percent 达 100% 的日期
- 实际开始时间 = 首条 percent > 0 的日期（或显式 actual_start_date）
- 任务当前进度 = 最新一条记录

### 4.3 天气月度记录

```text
project_id / month / precipitation_mm / temperature_c / sunshine_hours
```

### 4.4 水电资源指定

项目设置新增字段（仿 `housing_resource_id`），如 `water_resource_id` / `electricity_resource_id`（可空）。后端在月度聚合、成本聚合中把指定资源归入“水电”桶返回，不依赖资源自身 category。

### 4.5 低碳措施

```text
id / project_id
measure_type: PV | ELECTRIC_EQUIPMENT | RECYCLED_MATERIAL | GREYWATER | CUSTOM
kind: ADD(添加类) | REPLACE(替换类)
resource_ids: 添加类=[光伏资源]；替换类=[计划资源, 实际资源]
status: PLANNED(计划中) | IMPLEMENTED(已实施) | ABANDONED(未实施)
scale / implemented_date / note
```

节碳计算（后端统一逻辑，预估与实际复用）：

- 添加类（光伏）：资源碳排放因子为负，节碳 = 该资源 usage 总排放（负值贡献）
- 替换类（电动设备 / 再生建材 / 中水）：节碳 = Σ(计划资源用量×因子 − 实际资源用量×因子)，按资源流逐日计算
- 预估阶段用计划数据（计划编制时点一次）；评价阶段用实际 usage 数据自动得出

## 5. 各页面详细设计

### 5.1 计划编制（新增）

入口：优化结果页选定方案 → “编制计划”。

布局：

1. 顶部：方案摘要（工期 / 成本 / 碳排，来自所选解）
2. 甘特图（可编辑）：每工序支持开始偏移、策略模式切换、工期微调；前端依赖校验
3. 减碳措施区：添加 / 编辑措施（类型、资源选择、预估参数）
4. “预估计算”：调用后端估算接口，展示调整后工期 / 成本 / 碳排、每月分布、每项措施预估节碳、与原方案 delta
5. “保存为计划”：成为施工计划基线

### 5.2 施工进度（新增）

- 计划侧甘特（来自计划基线）叠加实际进度（按日记录）
- 每工序：当前进度 / 实际开始 / 实际完成（100% 日期）vs 计划
- 项目整体：计划工期 vs 实际工期（当前推算）

### 5.3 天气情况（新增）

- 月度表格录入（降水 / 气温 / 光照）+ 折线图
- v1 纯展示，不做与进度 / 排放的关联分析

### 5.4 碳排放与成本（增强）

在现有碳排放分析基础上：

- 类别桶增加“水电”（后端返回，前端 `categoryConfigMap` 补充）
- 新增成本区块：总成本 / 月均成本卡片、月度成本趋势（堆叠/折线，复用排放图组件模式）、成本 TopN
- 成本数据来自月度聚合接口的 `cost` 字段（= 用量 × 单价），ACTUAL/PLANNED 可切换

### 5.5 碳排放分布（评价）

本质 = “设置 → 碳排放图表”定义的图，直接复用 `TagChartsSection`：

- 预置“排放类别”维度 + 种子标签：建材隐含碳 / 施工机械 / 现场临时建筑 / 运输 / 施工用材 / 施工耗材 / 其它
- 资源默认归类（可覆盖）：机械类 → 施工机械；运输类 → 运输；材料类 → 施工用材；指定临时用房资源 → 现场临时建筑；指定水电资源 → 施工耗材（建议，待确认）
- 图表聚合接口需支持成本维度（饼图按 tag 聚合金额）

### 5.6 计划践行度（新增）

数据全部来自后端 `GET /evaluation/compliance`：

| 指标           | 计划侧       | 实际侧                  |
| -------------- | ------------ | ----------------------- |
| 总工期         | 计划基线     | 首条实际开始 ~ 最后完成 |
| 总成本         | 计划月度汇总 | usage × 单价 汇总       |
| 总碳排         | 计划月度汇总 | usage × 因子 汇总       |
| 各工序完成时间 | 计划基线     | 进度记录 100% 日期      |
| 材料用量差异   | 计划用量     | 实际用量（按资源）      |
| 每月成本       | 计划月度     | 实际月度                |
| 每月碳排       | 计划月度     | 实际月度                |

注：计划侧临时用房来自计划基线（按人数推导），实际侧为 usage 记录。

### 5.7 低碳措施（评价）

- 措施列表：类型 / 状态 / 预估节碳 / 实际节碳（自动聚合）/ 差额
- 状态由用户在施工阶段手动维护（计划中 / 已实施 / 未实施）
- 光伏等负因子资源的总排放（负值）在总碳排中自然体现，无需额外口径

## 6. 后端任务清单

### 计划阶段

| 编号 | 任务                                                     | 说明                                                                                                                    |
| ---- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| P1   | `POST /projects/{id}/plans/estimate`                     | 计划估算：入参任务调整 + 措施列表 → 重算工期（关键路径）/ 成本 / 碳排 / 月度分布 / 每项措施预估节碳；含依赖校验错误返回 |
| P2   | `POST /projects/{id}/plans` + `GET /projects/{id}/plans` | 保存 / 读取施工计划基线（任务快照 + 月度计划 + 措施清单 + 汇总）                                                        |
| P3   | 措施 CRUD                                                | `/projects/{id}/measures`，字段见 §4.5；创建于计划编制                                                                  |
| P4   | 措施节碳计算模块                                         | 同一套逻辑服务预估（计划数据）与实际（usage 数据）两次调用                                                              |

### 施工阶段

| 编号 | 任务               | 说明                                                                                                                                   |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| C1   | 工序进度记录 CRUD  | `/tasks/{task_id}/progress`（date + percent），按日；含任务聚合接口（当前进度 / 实际起止 / 完成日期）                                  |
| C2   | 天气月度 CRUD      | `/projects/{id}/weather`（month / precipitation / temperature / sunshine_hours）                                                       |
| C3   | 月度聚合扩展       | `monthly-emissions` 增加 `cost`（= 用量 × 单价），ACTUAL / PLANNED 均返回；成本 / 排放一次拿全                                         |
| C4   | 水电资源指定       | 项目设置新增 `water_resource_id` / `electricity_resource_id`；月度聚合把指定资源归入“水电”桶返回                                       |
| C5   | PLANNED 侧临时用房 | 计划侧临时用房排放（按人数推导）由计划基线数据承载；若 `monthly-emissions?usage_type=PLANNED` 需覆盖临时用房，后端注入推导记录（可选） |

### 评价阶段

| 编号 | 任务                                       | 说明                                                        |
| ---- | ------------------------------------------ | ----------------------------------------------------------- |
| E1   | `GET /projects/{id}/evaluation/compliance` | 一次返回全部践行度数据（§5.6 七项，计划 vs 实际），后端聚合 |
| E2   | 预置“排放类别”维度                         | 种子标签 + 资源默认归类（§5.5），可做成迁移 / 种子数据      |
| E3   | 图表聚合支持成本                           | `getChartPieData`（或新端点）按 tag 子树返回金额            |
| E4   | 措施实际节碳聚合                           | 从 usage 数据自动计算每项措施的实际节碳（复用 P4 模块）     |
| E5   | 施工完成判定                               | 全部工序进度 100% 后解锁评价阶段（可后端返回标志）          |

## 7. 前端任务清单

1. 侧边栏子菜单支持阶段分组标题
2. 计划编制页（甘特编辑 / 措施录入 / 预估结果 / 保存基线）
3. 策略比选页（合并现有两页 + 依赖变更引导）
4. 施工进度页（计划 vs 实际）
5. 天气页（录入 + 图表）
6. 碳排放与成本增强（水电桶 + 成本区块）
7. 日报处理增加按日进度录入
8. 评价：排放分布（预置图集）、践行度、低碳措施三页
9. `categoryConfigMap` 补充水电类别（若后端返回）
