# 项目设置

「设置」页面（左侧导航，icon dashboard）集中管理项目的各类配置，包含多个子页面。本文按使用顺序介绍。

## 碳排放总览

展示项目实际碳排放的整体概况：

- **总排放量**（t / kg 自动换算，≥1 万 kg 显示为 t）；
- 覆盖月度数、资源种类数；
- **按类别排放**：人工 / 机械 / 材料 / 运输等类别的排放占比。

> 该项目暂无碳排放数据时会提示并跳转到分析洞察。

## 项目信息

维护项目基本信息、规模、临时用房、地点、建筑概况与施工计划，详见[项目管理](./project)。

## 资源管理

创建 / 编辑资源、从公共资源导入、资源打标，详见[资源管理](./resources)。

## 资源限制（资源约束）

为资源设置**日用量上限**，优化时作为约束条件剔除超限方案：

- 新建：选择资源 → 填写最大日使用量（max_usage，浮点数）；
- 一个资源只能有一条约束（更新需用编辑而非新建）；
- 删除约束后该资源不再受限。

::: warning 重要前提
标准施工模式（全部工序模式 0）必须**不违反**资源约束，优化才能保证至少存在一个可行解。约束设置过严会导致优化失败（"未找到满足资源约束的可行解"）。
:::

::: tip 约束判定口径
系统对受约束资源，把每个工序的**总用量按其调整后工期均摊到每天**，取全项目每天的峰值与上限比较。因此：

- **加速施工（模式 1/3）会提高该资源的日峰值**——同一总用量被压缩到更短工期，属预期行为；
- **只有已设置的资源参与判定**：未设置上限的资源数量再多也不受限；
- 判定是基于均摊的**近似**，符合计划阶段资源按月录入的现状，并非逐日真实曲线。

详见[算法文档中的资源约束说明](../algorithm/nsga2)。
:::

## 材料复用（资源周转配置）

为**可周转材料**（模板、脚手架、集装箱等）配置周转次数，更精确地计算碳排放与成本：

| 字段                        | 说明                       |
| --------------------------- | -------------------------- |
| 资源                        | 选择材料资源               |
| 最大周转次数（max_reuses）  | 该材料理论可周转次数       |
| 实际周转次数（reuse_count） | 实际周转次数               |
| 影响成本（affect_cost）     | 是否同时折减单价（默认否） |
| 描述                        | 可选                       |

修正公式：`有效碳排放因子 = 原始因子 / (max(1, max_reuses) × max(1, reuse_count))`；`affect_cost=true` 时单价同样折减。

> 该配置同时作用于**月度排放报表**与**优化计算**（优化前对资源单价与碳排因子做预修正）。临时用房资源若配置了周转，其碳排也按此折减。

## 优化配置（NSGA2 参数）

项目级默认优化参数（在「分析洞察」新建运行时可覆盖）：

| 参数         | 说明                     |
| ------------ | ------------------------ |
| 种群大小     | 每代个体数量             |
| 最大代数     | 迭代次数上限             |
| 名义年利率   | 成本现值折现率（IRR）    |
| 加速工期比例 | 加速施工时的工期缩放比例 |
| 最大偏移天数 | 任务开始时间最大偏移     |

::: tip
这些参数与「分析洞察 → 开始优化」中的配置一致，这里保存的是项目默认值，便于统一管理。
:::

## 数据体检

「数据体检」是只读诊断页，从后端拉取**所有有使用记录的资源**，检查其碳排放因子与单价是否存在异常口径。它**不影响任何功能**，仅提示，帮助发现"漏填因子 / 单价导致的静默失真"。

入口：设置 → 数据体检（navOrder 9），或「碳排放总览」页顶部的提示条 → 查看体检。

- **用量口径**：全部 / 实际（ACTUAL）/ 计划（PLANNED）三种口径切换，决定哪些记录参与统计；
- **检查项**：

| 标志              | 级别 | 含义                                                               | 处理                                                                              |
| ----------------- | ---- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| `ZERO_FACTOR`     | 警告 | 有使用记录但碳排放因子为 0，其用量**不计入任何碳排结果**           | 若符合计算边界（如仅用于峰值人数 / 资源约束的工种）可忽略；否则去「资源管理」补填 |
| `NEGATIVE_FACTOR` | 提示 | 碳排放因子 < 0：碳汇资源（如光伏），「低碳措施」的添加类措施依赖它 | 符合预期即可                                                                      |
| `ZERO_PRICE`      | 提示 | 单价为 0 且有用量，其用量不计入成本                                | 视边界确认                                                                        |

> 碳排放计算边界是项目决策。软件**不在任何操作路径上拦截 0 或负值**——合法的 0（人员生活从水电统一核算、工种仅用于峰值人数与资源约束等）由你在体检页自行判断忽略。体检仅在"该资源存在使用记录"时才提醒，无用量的资源（如项目级常量"人员生活"）不会打扰。

## 计划基线过期检查（数据体检页内）

「数据体检」页同时提供**计划基线过期检查**：对比「计划编制」保存基线时的输入（任务 / 依赖 / 计划用量 / 资源单价与碳因子 / 周转配置 / 措施等）与当前数据，判断基线是否过期：

| 结果       | 含义                                                     | 处理                              |
| ---------- | -------------------------------------------------------- | --------------------------------- |
| 基线最新   | 基线输入与当前数据一致，无需重新保存                     | —                                 |
| 基线已过期 | 任务/依赖/用量/资源/措施等已变化，基线仍停留在旧数据快照 | 到「计划编制」重新预估并保存基线  |
| 尚未保存   | 项目还没有计划基线                                       | 到「分析洞察 → 计划编制」保存基线 |

::: warning 手动触发语义
过期状态**不会**在每次修改任务/资源等数据时自动更新（不监听业务变更），也不会在读取计划时实时计算——只有打开本页或点击「重新检查」时才更新落库。因此改动数据后需到本页执行一次检查，「计划编制」与「计划践行度」页才会显示对应的过期提示。
:::
