# 分析洞察（优化）

「分析洞察」是软件的核心页面（左侧导航，icon insights），包含四个子页面：

```
优化结果 → 碳排放分析 → 方案对比 → 施工模式对比
```

## 优化结果

### 运行列表

展示历史优化记录（按创建时间倒序），每条记录显示：名称（标签）、状态、当前代数 / 最大代数、创建时间。支持：

- **删除**：只能删除已完成的运行；
- **中断**：对运行中（PENDING / RUNNING）的任务可随时中断，中断后标记为失败。

### 新建优化运行

点击「开始优化」，配置参数：

| 参数              | 默认值 | 说明                                                             |
| ----------------- | ------ | ---------------------------------------------------------------- |
| 运行名称          | 无     | 可选标签，如"串行 #1"                                            |
| 种群大小          | 100    | 每代个体数量，越大搜索越充分但越慢                               |
| 最大代数          | 100    | 迭代次数上限                                                     |
| 名义年利率（IRR） | 0.05   | 折现率，用于成本现值计算（月折现率 = IRR/12）                    |
| 加速工期比例      | 0.8    | 加速施工时工期 × 该比例（如 0.8 = 缩短 20%）                     |
| 最大偏移天数      | 60     | 任务开始时间最大偏移（天），允许任务在非关键路径上延后以平衡资源 |
| 用量类型          | ACTUAL | 优化使用实际（ACTUAL）或计划（PLANNED）用量数据                  |

点击「开始优化」后：

1. 后端加载项目数据（工序、依赖、资源用量、约束、周转配置）；
2. 创建优化运行记录（含任务/依赖**快照**——后续修改工序不影响本次运行的回放）；
3. 后台启动 NSGA-II，前端**轮询进度**（当前代数 / 总代数）；
4. 运行完成（或失败、中断）后展示结果。

### 帕累托前沿可视化

运行成功后展示：

- **三维散点图**（帕累托前沿）：X 工期、Y 成本、Z 碳排放，每个点是一个帕累托最优解，支持拖拽旋转、滚轮缩放；
- **解集表格**：列出每个解的成本（万元）、工期（天）、碳排放、峰值人数、临时用房间数、模式组合；
- 点击某个解可**选中方案**（选中方案高亮），并可加入对比列表。

### 帕累托解的构成

每个解是一个完整施工方案：

```json
{
  "id": 1,
  "cost": 386.5, // 现值成本（万元）
  "emission": 1240.6, // 碳排放（t）
  "duration": 55.0, // 总工期（天）
  "strategies": [
    { "taskId": 1, "mode": 0, "start": 0 }, // 标准施工，第 0 天开始
    { "taskId": 2, "mode": 1, "start": 10 }, // 加速施工，第 10 天开始
    { "taskId": 3, "mode": 2, "start": 25 } // 低碳施工
  ],
  "violations": [],
  "peakPersonnel": 96,
  "housingRooms": 29
}
```

`mode` 取值：0 标准 / 1 加速 / 2 低碳 / 3 加速低碳（详见[四种施工模式](../algorithm/modes)）。

::: tip

- 帕累托前沿上的解没有绝对优劣，选择取决于对成本 / 工期 / 碳排的偏好；
- 若运行失败提示"未找到满足资源约束的可行解"，请检查[资源限制](./settings)是否过严；
- 资源约束的判定口径：把每工序总用量**按调整后工期均摊**后取每日峰值比较，且**只对已配置上限的资源生效**——加速会提高日峰值，未配置的资源不受限。详见[算法文档中资源约束说明](../algorithm/nsga2)；
- 优化运行基于运行创建时的数据快照，运行中修改工序不影响该次运行。
  :::

## 计划编制（将方案落为计划基线）

「计划编制」把帕累托前沿上的一个方案**固化为项目计划基线**，供评价阶段对照：

1. **方案摘要**：选择优化运行与其中的推荐方案，展示该方案的工期 / 成本 / 碳排；
2. **减碳措施**：添加 ADD（负碳因子资源，如光伏）或 REPLACE（计划资源 → 实际资源替换）措施，预估节碳；
3. **预估计算**：按当前方案与措施重算工期 / 成本 / 碳排与月度分布；
4. **保存**：保存为**计划基线**（正式，参与评价对照）或**草稿**（不参与）。

::: tip 基线过期提示
保存基线后，若任务 / 依赖 / 计划用量 / 资源 / 周转配置 / 措施等发生变化，基线与当前数据不再一致。页面会显示「数据已变更，建议重新预估」提示——该状态在「设置 → 数据体检 → 计划基线过期检查」手动检查时更新，重新预估并保存基线后自动消除。
:::

## 方案对比

用于**横向比较多个方案**（同一运行内或跨运行）：

- 最多同时加入 **5 个方案**对比；
- **雷达图对比**：成本、工期、碳排三个维度的归一化对比；
- **指标对比表**：列出各方案的详细指标与模式组合；
- **甘特图回放**：按该运行的任务/依赖快照，回放选中方案的施工排程（各工序模式与开始时间）。

### 合并多轮优化结果

通过「合并」功能，可将多个**已完成**运行的帕累托解合并为新的非支配前沿：

- 参与合并的运行必须属于同一项目且状态为成功；
- 各运行覆盖的任务 id 集合必须一致（否则返回 422）；
- 合并结果剔除被支配与目标值重复的解。

::: tip
合并适合"同配置多次运行取并集"或"不同参数运行后综合比较"的场景，得到更完整的帕累托前沿。
:::

## 施工模式对比

针对"**所有工序都采用某一种模式**"的假设性方案进行对比（如全标准 vs 全加速 vs 全低碳 vs 全加速低碳），直观展示四种极端策略的成本 / 工期 / 碳排差异：

- 各方案的成本、工期、碳排对比；
- 与帕累托前沿中"幸存解"（同模式组合的解）对照。

## 常用操作路径

| 目标                   | 操作                                      |
| ---------------------- | ----------------------------------------- |
| 跑一次优化             | 优化结果 → 开始优化 → 配置参数 → 等待完成 |
| 查看某方案细节         | 帕累托图点击解 / 表格行选中               |
| 对比几个方案           | 勾选加入对比 → 方案对比                   |
| 综合多轮结果           | 方案对比 → 合并                           |
| 中断过慢的任务         | 运行列表 → 中断                           |
| 比较四种模式的极端效果 | 施工模式对比                              |
