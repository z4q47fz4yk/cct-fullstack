# 资源管理

资源是成本与碳排放计算的基础数据。资源管理入口：**设置 → 资源管理**。

## 资源类别

| 类别              | 说明     | 示例                           |
| ----------------- | -------- | ------------------------------ |
| 人工（labor）     | 施工人员 | 泥工、钢筋工、木工、砌筑工     |
| 机械（machinery） | 施工机械 | 挖掘机、塔吊、人货梯、锚固钻机 |
| 材料（material）  | 建筑材料 | 商品混凝土、钢筋、模板         |
| 运输（transport） | 运输工具 | 重型卡车、渣土车               |
| 其他（others）    | 其他     | 人员生活、临建设施             |

::: warning 类别影响优化结果
优化时施工模式公式按类别生效：**加速施工**改变机械与人工的成本/碳排；**低碳施工**改变机械成本与机械、人工碳排；材料与运输不随模式变化。因此类别务必填对。
:::

## 新建资源

点击「新建资源」，填写：

| 字段       | 说明                       |
| ---------- | -------------------------- |
| 资源名称   | 项目内唯一                 |
| 资源类型   | 上述五类之一               |
| 单价       | 元 / 单位                  |
| 计量单位   | 如 工日 / 台班 / m³ / 车次 |
| 碳排放因子 | kg / 单位                  |
| 描述       | 可选                       |

::: tip 人员生活资源
名称为"人员生活"的资源比较特殊：优化时其碳排放因子被用于计算**人员生活碳排放**（按总工日数 × 因子）。它通常不会被日报导入，而是作为项目级常量配置。
:::

::: tip 碳排放因子的取值语义

- **0（零碳因子）**：表示该资源**不进入碳排放计算**。多用于把某些类别的排放统计到其他资源（如"人员生活"因子置 0、统一从水电核算），或仅用于**峰值人数 / 资源约束**统计的工种（泥工、瓦工等）。软件不会拦截 0，但若它有用量记录，会在[数据体检](./settings#数据体检)中以警告列出，方便你确认是有意为之还是漏填。
- **负值（碳汇）**：表示该资源本身**吸收/抵消碳排放**（如光伏发电），"低碳措施"的添加类措施依赖负因子资源。
- 若某资源被列为 0 或负值是**有意配置**，在[数据体检](./settings#数据体检)中无视对应提示即可。
  :::

## 从公共资源导入

「公共资源」是软件内置的**全局只读资源字典**（如常见机械、材料），可按类别批量拷贝到当前项目：

1. 点击「从公共资源导入」；
2. 按 **ids** 或 **类别** 选择要导入的资源；
3. 确认后，目标项目内**已存在同名资源时自动跳过**，返回 `copied / skipped / not_found` 明细。

导入后资源变为项目资源，可自由编辑单价与碳排放因子。

## 资源标签

资源可以打标签（如"施工机械""临建设施"），用于[碳排放分析](./emission)中的分类统计。入口：资源列表 → 标签操作 → 从扁平标签中多选。

## 资源统计

页面顶部展示资源数量一览（按类别统计）：人工、机械、材料、运输、其他各多少种。
