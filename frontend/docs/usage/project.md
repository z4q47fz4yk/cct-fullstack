# 项目管理

<BackToProject />

> 从应用跳转到本文档时（URL 带 `?projectId=123`），上方会显示「回到项目」链接；直接访问文档站则无此链接。

项目是软件中所有业务数据的顶层容器。本文介绍项目的创建、切换与信息维护。

::: tip 在系统中操作
以下操作均需在系统中完成，点击 <AppLink to="/">在系统中打开</AppLink>（项目列表页）开始。
:::

## 创建项目

打开软件首页（应用根路径，如开发环境 <http://localhost:5173/>），点击「新建项目」按钮，填写：

- **项目名称**（必填）：如"某商业综合体项目"；
- **项目描述**（可选）：简要说明项目内容。

点击保存后自动进入该项目。

## 项目列表与切换

首页展示所有项目（卡片列表）。点击任意项目卡片进入该项目。项目之间数据完全隔离——切换项目后，任务、资源、日报、优化记录都切换到对应项目的数据。

## 项目信息维护

进入项目后，通过左侧导航进入 **设置 → 项目信息**，可以维护：

### 基本信息

| 字段     | 说明                       |
| -------- | -------------------------- |
| 项目名称 | 必填                       |
| 项目描述 | 可选                       |
| 项目状态 | 启用 / 停用（`is_active`） |

### 项目规模

| 字段           | 说明       |
| -------------- | ---------- |
| 占地面积（m²） | 项目占地   |
| 建筑面积（m²） | 总建筑面积 |

### 临时用房

用于优化时计算**临时用房间数**与**临时用房碳排放**（例如活动板房、集装箱宿舍）：

| 字段         | 说明                                     |
| ------------ | ---------------------------------------- |
| 临时用房资源 | 从项目资源中选择对应资源（如"临时用房"） |
| 安全系数     | 建议值不低于 1.0，默认 1.2               |
| 每间人数     | 每间临时用房居住人数，默认 4             |

计算逻辑：优化中根据各方案的**峰值施工人数**推算所需房间数，再乘以临时用房资源的碳排放因子（并按周转次数折减），计入方案总碳排放。

### 项目地点

| 字段     | 说明     |
| -------- | -------- |
| 省份     | 下拉选择 |
| 城市     | 下拉选择 |
| 详细地址 | 文本输入 |

### 建筑概况

| 字段                                                                                    | 说明                           |
| --------------------------------------------------------------------------------------- | ------------------------------ |
| 地下建筑面积 / 地上建筑面积                                                             | m²                             |
| 结构类型                                                                                | 多选（框架结构、剪力墙结构等） |
| 预制率                                                                                  | %                              |
| 设计使用年限                                                                            | 年                             |
| 结构安全等级 / 地基基础设计等级 / 桩基设计等级 / 耐火等级 / 抗震设防烈度 / 地下防水等级 | 等级选择                       |

### 施工计划

| 字段                | 说明               |
| ------------------- | ------------------ |
| 计划开工 / 竣工日期 | 日期               |
| 实际开工 / 竣工日期 | 日期               |
| 施工碳排放限额      | 项目碳排目标（kg） |

> 碳排放限额目前作为项目参考信息记录，用于与优化结果对比。

## 删除项目

「删除项目」会**级联删除该项目下所有数据**（工序、资源、日报、优化记录等），属不可逆操作。系统会弹出二次确认，请谨慎操作。
