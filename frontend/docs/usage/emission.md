# 碳排放分析

碳排放分析用于**从多角度拆解项目碳排放构成**。核心机制是"标签 → 切片 → 图表"三级配置：

```
标签（扁平，名称项目内唯一，可分组展示）
  └── 打标（资源 / 工序 / 用量 三粒度，+ 资源分类内置标签）
        └── 切片（图表的单元 = 若干标签组；同组且、组间或）
              └── 图表定义（若干切片 → 饼图）
```

## 第一步：配置标签

入口：**设置 → 碳排放标签**。

标签为**扁平**结构：名称在项目内唯一；**分组（group）**仅用于界面归类（材料 / 机械 / 工序 / 部位 / 运输货物…），
不参与碳排放统计。空分组显示为「未分组」。

示例：把原来的"维度树"展平为扁平的标签列表：

| 分组   | 标签                                   |
| ------ | -------------------------------------- |
| 建材   | 商品混凝土、钢筋、模板                 |
| 机械   | 挖掘机、塔吊、人货梯                   |
| 水电   | 外购电力、外购自来水、柴油、光伏发电   |
| 运输货物 | 渣土、建材、生活垃圾（自动打标源）   |

## 第二步：打标

三个打标粒度，应对不同拆分需求：

| 粒度                     | 说明                 | 适用场景                                         |
| ------------------------ | -------------------- | ------------------------------------------------ |
| **资源**（resource_tag） | 给资源打标签         | 按资源类型拆分，如"施工机械"                     |
| **工序**（task_tag）     | 给工序打标签         | 按施工部位拆分，如"地下工程支护"                 |
| **用量**（usage_tag）    | 给某条用量记录打标签 | 运输货物分类（同一车辆运多种货时必须用用量粒度） |

打标入口：

- 资源：设置 → 资源管理 → 标签；
- 工序：任务管理 → 标签；
- 用量：资源使用录入 → 历史 → 标签（日报运输类导入时会按货物名称自动打同名标签）。

> 说明：一条用量参与统计的"合并标签" = 其**资源标签 ∪ 工序标签 ∪ 用量标签 ∪ 资源分类内置标签**
> （如该资源分类是"材料"，则恒带一个内置「材料」标签）。标签按名称去重合并。

## 第三步：配置图表

入口：**设置 → 碳排放图表**。

创建图表定义，核心是配置若干**切片**：

| 元素     | 说明                                                               |
| -------- | ------------------------------------------------------------------ |
| 图表名称 | 如"施工用材占比"                                                   |
| 切片     | 每个切片一个名称（饼图扇区名）+ 若干**标签组**                     |
| 标签组   | 组内标签为**且**（须全部命中），组与组之间为**或**（命中任一即计入） |
| 分类内置 | 标签选择器里可直接选「材料 / 机械 / 运输 / 人工 / 其他」，按资源类别命中，无需打标 |

### 命中逻辑示例

- **单一标签**：切片"地下工程支护"绑定标签 地下工程支护 → 打了该标签（资源 / 工序 / 用量任一）的用量计入；
- **同组且**：切片"支护与用材"的两个标签放同一组（且）→ 须资源同时带两个标签才计入；
- **不同组或**：第二个组另放标签（或）→ 命中任一组即可；
- **分类过滤**：切片绑定内置「材料」标签 → 仅材料类资源的用量计入（等价旧版"资源分类过滤"，无需再选 resourceCategories）。

> 碳排放口径与月度报表一致：按 usage_snapshot 物化视图聚合用量后，Python 层应用**资源周转折减**再乘碳排放因子计算排放。
> 物化视图约每 30 分钟自动刷新一次（可在「数据体检」查看刷新时间 / 手动刷新）。

### 关于切片重叠

写入打标 / 切片配置**不再做互斥校验**：同一用量命中同一图表的多个切片时会**重复计入**（如实反映重叠），
避免在操作路径上设卡。请在 **设置 → 数据体检 → 标签/切片配置体检** 检查切片标签重叠并修正。

## 第四步：查看图表

- **设置 → 碳排放总览**：项目整体碳排放概览（总排放、月度数、资源数、按类别排放）；
- **分析洞察 → 碳排放分析**：展示各图表饼图，支持碳排放 / 成本口径切换；
- **分析洞察 → 碳排放分布**：全部图表的分布视图。

## 常见问题

| 问题                      | 处理                                                                             |
| ------------------------- | -------------------------------------------------------------------------------- |
| 饼图数据为空              | 检查标签是否已打（资源 / 工序 / 用量哪个粒度）、切片命中组是否与该粒度一致       |
| 同一用量出现在多个切片中  | 切片标签重叠导致重复计入 → 到「数据体检」查看重叠切片，调整图表配置             |
| 运输类数据拆分不准        | 运输应按**用量**粒度打标（同一车辆运多种货物时按资源打标无法拆分）               |
| 想按资源类别统计          | 切片直接绑定内置「材料 / 运输…」标签即可，无需给资源打额外标签                  |
| 饼图数据不是最新          | 数据源物化视图约 30 分钟刷新；改标后可到「数据体检 → 立即刷新」强制刷新         |

{ "id": 11, "name": "施工用材", "group": "建材", "description": "" }

// 图表定义（含切片；slices 顺序即饼图顺序）
{
  "id": 1,
  "name": "施工用材占比",
  "chartType": "PIE",
  "slices": [
    {
      "id": 21,
      "name": "地下工程支护",
      "sortOrder": 0,
      "tags": [
        { "tagId": 11, "tagName": "施工用材", "group": 0, "isBuiltin": false },
        { "tagId": -3, "tagName": "材料", "group": 0, "isBuiltin": true }
      ]
    }
  ]
}

// 饼图数据（PieSlice，value 单位跟随口径：kgCO2e 或 元）
[{ "name": "地下工程支护", "value": 45230.5, "sortOrder": 0 }]
