# 资源使用录入

「资源使用录入」页面（左侧导航，icon edit_note）用于**手动录入**资源使用情况、查看历史记录与统计数据。包含三个 Tab：**录入 / 历史 / 统计**。

::: tip
与[日报处理](./daily-report)的批量导入不同，手动录入适合少量补充或修正数据，例如：日报没覆盖到的资源、计划用量（PLANNED）、补录某天数据。
:::

## 录入

录入 Tab 用于批量创建某一天（默认今天）的资源使用记录：

1. 选择**日期**；
2. 添加多行记录，每行选择：
   - **工序（任务）**
   - **资源分类** → **资源**（级联选择）
   - **使用量**
3. 选择**用量类型**：
   - `ACTUAL`（实际）：实际发生的用量（优化默认使用）；
   - `PLANNED`（计划）：计划用量（可用于优化对比、计划排放分析）；
4. 点击保存，批量写入数据库（一批记录属于同一个**手动录入批次**，方便追溯）。

::: warning 唯一约束
同一项目、同一工序、同一天、同一资源、同一用量类型只能存在一条记录。重复录入会报 409 冲突，请先到「历史」中修改或删除原记录。
:::

## 历史

历史 Tab 用于查询与维护已有记录：

- **过滤条件**：
  - 开始 / 结束日期（按使用日期过滤）
  - 批次 ID
  - 用量类型（ACTUAL / PLANNED / 全部）
  - 任务筛选、资源筛选
- 表格展示每条记录：日期、工序、资源、数量、类型、批次；
- 支持**编辑**（数量、工序、资源等；批次字段创建后不可变）与**删除**；
- 支持给用量记录**打标签**（usage_tag，如运输类日报自动打的"货物类别"标签，可在此手动补标）。

## 统计

统计 Tab 以图表形式展示资源使用与排放情况：

- 选择要对比的资源（可多选）与时间范围；
- 展示所选资源随时间的**使用量 / 排放量曲线**（按 ACTUAL / PLANNED 分别或合并展示）。

## 常见问题

| 问题                          | 处理                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------ |
| 保存报"关联的工序/资源不存在" | 所选工序或资源已被删除，重新选择                                               |
| 保存报"已存在记录"            | 同一天同一工序同一资源已录入，去「历史」修改                                   |
| 历史列表为空                  | 检查过滤条件（日期范围、类型、任务/资源筛选）                                  |
| 统计图表为空                  | 所选资源在该时间段没有对应类型的数据，尝试切换 ACTUAL / PLANNED 或扩大日期范围 |

## 数据结构参考

```json
// 批量创建请求（ResourceUsageBatchCreate）
{
  "usageDate": "2025-12-14",
  "usageType": "ACTUAL",
  "items": [
    { "taskId": 5, "resourceId": 101, "quantity": 4.0 }
  ]
}

// 使用记录（ResourceUsageResp）
{
  "id": 2001,
  "taskId": 5,
  "resourceId": 101,
  "usageDate": "2025-12-14",
  "quantity": 4.0,
  "usageType": "ACTUAL",
  "batchId": "3f2a9c10-...",
  "manualBatchId": 7
}
```
