# 日报处理

日报处理是软件最主要的**数据获取方式**：上传施工现场的 Excel 施工日报，自动解析出资源使用情况，核对修正后分配到具体工序，最后提交入库。

入口：左侧导航「日报处理」（icon description），是一个 **5 步向导**：

```
导入日报 → 核对资源 → 分配到工序 → 确认提交 → 完成
```

::: tip
日报处理的数据在提交前都保存在导入批次（import_batch）中，**不会**污染正式数据。中途离开可稍后继续（状态按项目持久化在浏览器本地）。
:::

## 第一步：导入日报

1. 选择**使用日期**（日报所属日期）；
2. 上传 Excel 文件（支持 .xlsx / .xls）；
3. 点击解析，系统自动识别日报内容。

### 支持的日报格式

解析器按**数据块**识别三类内容（示例见 [20251214 施工日报](../guide/20251214.csv)）：

| 数据块 | 关键字                           | 解析字段                         |
| ------ | -------------------------------- | -------------------------------- |
| 人员   | "现场人员" + "人员数量"          | 工种名称、人数                   |
| 机械   | "施工机械" + "数量" + "机械型号" | 机械名称（型号合并）、台班数     |
| 运输   | "货物类别 / 运输工具 / 车次"     | 运输工具名称、车次、**货物类别** |

> 例如日报中"施工机械：挖机，数量：4台，型号：SE135-9W"会解析为资源"挖机-SE135-9W"、数量 4。不同施工单位的日报格式可能不同，解析器按关键字正则匹配，**无法识别的部分会给出解析警告**。

### 解析结果

解析成功后展示资源条目列表，每条包含：类别、资源名称、（运输类）货物类别、资源用量、单位、**匹配状态**：

| 状态                    | 含义                                     |
| ----------------------- | ---------------------------------------- |
| 精确匹配（EXACT_MATCH） | 项目资源字典中已存在同名资源，可直接使用 |
| 未匹配（NEW）           | 项目中没有该资源，需要新建或跳过         |

## 第二步：核对资源数据

对每条解析出的资源进行确认：

- **使用已有资源**：名称与项目资源一致（精确匹配默认选择此项）；
- **新建资源**：为未匹配的资源创建新资源（需补充类别、单价、单位、碳排放因子等）；
- **跳过**：忽略该条目（如无用的合计行、"/" 占位行）。

::: tip
建议先在「设置 → 资源管理」完善资源字典（或从公共资源导入），减少手工新建的工作量。新建资源后，其单价与碳排放因子会进入后续的成本 / 碳排计算。
:::

## 第三步：分配到工序

将每一项资源的使用量分配到具体工序。两种视图：

- **按工序汇总**：选择工序后，为各资源填写分配数量；
- **按资源汇总**：查看每种资源分配到各工序的数量。

约束：

- 分配数量之和**不能超过**解析出的总量；
- 数量为 0 的分配不会提交；
- 一个（任务, 车辆）存在多种货物类别时，提交会失败——需要调整分配（避免触碰唯一约束或静默丢失标签）。

## 第四步：确认提交

展示提交前汇总：

- **资源总数**、**分配工序数**；
- 按工序 / 按资源的分配明细。

确认无误后点击提交，数据一次性写入正式用量表（`task_resource_usage`）。

::: warning
提交是不可逆操作，系统会弹出二次确认。提交后如需修改，请到「资源使用录入 → 历史」中编辑或删除对应记录。
:::

## 第五步：完成

提交成功页展示本次导入的资源项数与涉及工序数。可「继续处理新日报」开始下一份，或「返回首页」。

## 运输类日报的特殊处理

运输块解析出的条目带有**货物类别**（cargo）字段：

- 提交入库时，系统按货物名称精确匹配项目内「运输货物」维度的标签，并自动给用量打上 `usage_tag`；
- **匹配不到时跳过**（不阻断导入），可事后在「资源使用录入 → 历史」中手动补标；
- 若同一（任务, 车辆）存在多种货物类别，提交会失败，需调整分配。

## 常见问题

| 问题                   | 处理                                                        |
| ---------------------- | ----------------------------------------------------------- |
| 解析后资源全是"未匹配" | 完善资源字典或使用公共资源导入；也可逐条新建                |
| 解析警告很多           | 日报格式与软件预期差异大，核对每一条解析结果                |
| 提交报"重复记录"       | 当天该工序该资源已有数据，到「资源使用录入 → 历史」查看处理 |
| 分配数量超总量         | 减少分配量，确保各工序分配之和 ≤ 解析总量                   |
