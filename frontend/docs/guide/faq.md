# 常见问题

## 部署与环境

### 后端启动报错"数据库连接失败"？

1. 确认 PostgreSQL 已启动且数据库已创建；
2. 检查 `backendv2/.env` 中的 `DATABASE_URL` 是否正确（用户名、密码、库名）；
3. 确认已执行迁移：`uv run --group migrate alembic upgrade head`。

### 前端页面打不开 / 接口请求失败？

1. 确认后端已启动（`uv run uvicorn src.app:app --reload --reload-dir src`）；
2. 确认前端 `src/hey-api.ts` 中 `baseUrl` 指向后端地址；
3. 打开浏览器开发者工具（F12）→ Network，查看具体请求错误。

## 日报导入

### 日报解析后有很多"未匹配"的资源？

这是正常现象。日报中的资源名称（如"泥工"）与项目资源字典中的名称需要一一对应：

- **精确匹配**：自动使用已有资源；
- **未匹配**：可选择「新建资源」（补充单价、碳排因子）或「跳过」；
- 建议先在「设置 → 资源管理」中完善资源字典，或使用「从公共资源导入」批量拷贝预置资源，可减少手工匹配工作量。

### 日报支持的 Excel 格式？

软件按**数据块**识别日报内容：人员（现场人员 / 人员数量）、机械（施工机械 / 数量 / 机械型号）、运输（货物类别 / 运输工具 / 车次）。不同施工单位的日报格式可能不同，解析器按关键字正则匹配，**格式不标准的内容可能解析失败或产生警告**，解析后务必在"核对资源数据"步骤人工检查。

可参考示例文件：[20251214 施工日报示例](../guide/20251214.csv)。

### 导入提交时报"同一任务同一天同一资源已存在"？

系统要求同一工序、同一天、同一资源只能有一条记录。该错误表示当天数据已存在（可能重复导入或与手动录入冲突）。可以在「资源使用录入 → 历史」中查看当天记录，修改或删除后再提交。

## 任务与进度

### 创建任务时提示"存在循环依赖"？

工序之间的前置关系不能成环（如 A→B→A）。请检查依赖设置，移除造成循环的前置关系。系统在添加前置任务时会自动检测并拒绝。

### 为什么甘特图里有些任务标红？

红色表示**关键路径**上的任务（总浮动时间为 0）。关键路径决定项目总工期，压缩关键路径上的工序工期才能缩短总工期。

### 优化时任务编码"AUTO-N"会重复吗？

任务编码按项目隔离（`(project_id, code)` 唯一），不同项目可以出现相同的 `AUTO-N`，同一项目内不会重复。

## 优化

### 优化一直停在"运行中"？

- 优化是后台任务，种群大、代数多时耗时较长，属正常现象；
- 可在「分析洞察」中观察运行进度（当前代数 / 最大代数）；
- 如需停止，点击「中断优化」；中断后该次运行标记为失败，不产生结果。

### 优化失败："未找到满足资源约束的可行解"？

NSGA-II 要求至少存在一个不违反资源约束的方案。请检查：

1. 「设置 → 资源限制」中的日用量上限是否过小；
2. 标准施工模式下资源用量是否已经超限（资源约束的前提是标准方案可行）；
3. 可适当放宽约束或删除约束后重试。

### 帕累托解数量很少？

- 增大**种群大小**与**最大代数**可让算法搜索更充分；
- 检查约束是否过于严格；
- 目标间存在强冲突时，前沿解数量本身可能较少，可尝试在「方案对比」中比较不同运行。

### 不同优化运行的结果可以合并吗？

可以。「分析洞察 → 方案对比 → 合并」可将多个已完成运行的结果合并为新的帕累托前沿（剔除被支配与重复解）。要求各运行覆盖的任务集合一致。

## 碳排放

### 碳排放怎么算出来的？

碳排放 = Σ（资源用量 × 碳排放因子），其中：

- 资源用量来自资源使用记录（实际 / 计划）；
- 碳排放因子在资源管理中配置；
- 配置了周转的材料按周转次数折减；
- 优化中的碳排放还受施工模式影响（详见[四种施工模式](../algorithm/modes)）。

### 饼图里看不到数据？

饼图按「图表定义」绑定标签切片聚合碳排放，请确认：

1. 「设置 → 碳排放标签」中已创建标签，且资源 / 工序 / 用量已打上对应标签；
2. 「设置 → 碳排放图表」中已创建图表并配置切片（标签组）；
3. 项目存在对应日期范围的资源使用数据。

### 饼图里同一用量出现在多个切片？

切片之间标签重叠时，命中重叠的用量会在多个切片**重复计入**（输入路径不再做互斥拦截）。
可在「设置 → 数据体检 → 标签 / 切片配置体检」查看重叠切片并修正图表配置。

## 其他

### 软件支持多项目吗？

支持。首页可创建多个项目，每个项目的工序、资源、日报、优化记录完全隔离；切换项目后所有页面自动切换到该项目的数据。

### 资源类别为什么影响优化？

优化按资源类别套用施工模式公式：加速施工只影响**机械**与**人工（施工/生活）**的成本与碳排，低碳施工只影响**机械**与**人工施工**碳排及**机械**成本，材料与运输不受模式影响（详见[四种施工模式](../algorithm/modes)）。因此录入资源时**务必选择正确的类别**。

### 数据存在哪里？会不会丢？

所有业务数据保存在 PostgreSQL 数据库（通过 Alembic 迁移管理表结构）。日报导入过程的数据（解析结果、分配结果）保存在 `import_batch` 批次表中，未提交前不写入最终用量表。请定期备份数据库。
