# 四种施工模式

优化时，每个工序可以在四种**施工模式**中选择一种。施工模式定义了"从标准策略转变为该模式时，工序成本、工期、碳排放三者之间的关系"。

| 模式         | 编码 | 工期 | 成本               | 碳排放              |
| ------------ | ---- | ---- | ------------------ | ------------------- |
| 标准施工     | 0    | 不变 | 不变               | 不变                |
| 加速施工     | 1    | 缩短 | 机械、人工成本上升 | 人员生活碳排减少    |
| 低碳施工     | 2    | 不变 | 机械成本 +20%      | 机械、人工碳排 −40% |
| 加速低碳施工 | 3    | 缩短 | 组合               | 组合                |

## 标准施工（模式 0）

以数据库中现有数据（标准工期的资源用量）为基准。**这是优化解空间的基准方案**，所有模式的影响都相对它计算。

## 加速施工（模式 1）

通过**延长每日工作时长、增加机械设备数量**来加速。总工作量保持不变，因此机械等产生的碳排放不变；工期缩短使工人生活消耗减少，从而降低生活碳排放。

- 工期：`T_G = T_N × 加速工期比例`（默认 0.8，即缩短 20%）；
- 成本：
  - 机械、人工施工成本上升：`C_G = (1 + 1.5 × ΔT/T_N) × C_N`，其中 `ΔT = T_N − T_G`；
  - 人员生活成本下降：`C_G = (1 − ΔT/T_N) × C_N`；
- 碳排放：
  - 机械、人工施工、材料、运输：不变；
  - 人员生活：`E_G = (T_G/T_N) × E_N`（生活天数变少）。

::: tip 1.5 为经验系数
公式中的 1.5 是行业经验值，表示加速施工时机械/人工成本的上升幅度大于工期的压缩幅度。
:::

## 低碳施工（模式 2）

通过**升级机械设备**完成低碳目标：

- 成本：机械成本 +20%（`C_G = 1.2 × C_N`）；
- 碳排放：机械与人工施工碳排 −40%（`E_G = 0.6 × E_N`）；
- 材料、运输、人员生活不受影响；
- 建筑垃圾理论上减少 15%，但软件暂未纳入建筑垃圾类别，先不予考虑。

## 加速低碳施工（模式 3）

加速与低碳模式**同时生效**：

- 成本：机械 `1.2 × (1 + 1.5 × ΔT/T_N)`，人工施工 `1 + 1.5 × ΔT/T_N`，生活 `1 − ΔT/T_N`；
- 碳排放：机械、人工施工 ×0.6，人员生活 ×`T_G/T_N`。

## 影响汇总表

### 碳排放变化（(E−E_N)/E_N）

| 类别     | 标准 | 加速    | 低碳 | 加速低碳 |
| -------- | ---- | ------- | ---- | -------- |
| 材料     | -    | -       | -    | -        |
| 机械     | -    | -       | −40% | −40%     |
| 人员施工 | -    | -       | −40% | −40%     |
| 人员生活 | -    | −ΔT/T_N | -    | −ΔT/T_N  |
| 运输     | -    | -       | -    | -        |

### 成本变化（C/C_N）

| 类别     | 标准 | 加速           | 低碳 | 加速低碳             |
| -------- | ---- | -------------- | ---- | -------------------- |
| 材料     | -    | -              | -    | -                    |
| 机械     | -    | 1 + 1.5·ΔT/T_N | 120% | 1.2·(1 + 1.5·ΔT/T_N) |
| 人员施工 | -    | 1 + 1.5·ΔT/T_N | -    | 1 + 1.5·ΔT/T_N       |
| 人员生活 | -    | 1 − ΔT/T_N     | -    | 1 − ΔT/T_N           |
| 运输     | -    | -              | -    | -                    |

## 软件中的实现

- 优化问题的**决策变量**之一就是每个工序的模式（整数 0~3）；
- 加速模式的**加速工期比例**由用户配置（默认 0.8）；
- 模式只作用于**机械、人工（施工/生活）**类别；材料与运输的成本碳排不随模式变化；
- 因此资源类别填错（如把机械填成材料）会直接影响优化结果的正确性。
