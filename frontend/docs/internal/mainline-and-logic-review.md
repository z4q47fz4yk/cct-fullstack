# 使用主线梳理与软件逻辑设计审查报告

> 性质：内部设计审查文档（v1，2026-03；v1.1 更新：C-4/B-9 已通过移除 lag 字段修复；v1.2 更新：C-2/C-3 经产品复核）。基于 `backendv2` 源码逐行核验 + 前端页面结构梳理。
> 用途：先建立"用户使用主线"，再沿主线逐环节检查逻辑设计的不合理之处，作为后续改进的输入。

---

## 第一部分：使用主线（用户视角）

### 0. 总览

软件的实际页面结构已经按"阶段"组织（`分析洞察` 下分 计划阶段 / 施工阶段 / 评价阶段），主线与其一一对应：

```
阶段0 项目准备         创建项目 + 项目信息（临时用房 / 计划日期 / 碳限额）
        │
阶段1 计划阶段 ──→ 产出「计划基线」────────────────────────────┐
  1.1 任务管理：建工序（工期/完成度）+ 依赖（FS/SS/FF/SF）        │
        │        → CPM 实时算关键路径/总工期（甘特图）            │
  1.2 资源管理：资源（类别/单价/碳因子）+ 公共资源导入 + 打标      │
  1.3 资源使用录入：录入 PLANNED / ACTUAL 用量（唯一的 PLANNED 入口）│
  1.4 设置：资源限制（日上限）/ 材料复用（周转折减）/ 优化配置      │
        │                                                          │
  1.5 优化结果：NSGA-II 多目标优化 → 帕累托前沿（选解）            │
  1.6 计划编制：选解 + 减碳措施（ADD/REPLACE）→ 预估 → 保存基线 ──┘
        │
阶段2 施工阶段 ──→ 产出「实际数据」
  2.1 日报处理：导入 Excel → 核对资源 → 分配到工序 → 提交（ACTUAL + 运输标签 + 可选进度）
  2.2 资源使用录入：手工补录 ACTUAL / PLANNED
  2.3 施工进度：工序按日进度 + 天气 + 全景甘特 + 月度碳排/成本
        │
阶段3 评价阶段 ──→ 产出「复盘对照」
  3.1 碳排放分布：标签切片饼图（碳排放/成本双口径）
  3.2 计划践行度：计划基线 vs 实际（项目完成后解锁评价）
  3.3 低碳措施：预估节碳 vs 实际节碳
        │
迭代 ──── 施工数据变化 → 重跑优化 → 更新基线 → 再评价
```

主菜单（日报处理 → 任务管理 → 资源使用录入）是**施工日常操作**入口；`分析洞察` 是**阶段化视图**入口。

### 1. 阶段 0：项目准备（一次性）

| 操作                | 输入数据                         | 影响什么                                                |
| ------------------- | -------------------------------- | ------------------------------------------------------- |
| 创建项目            | 名称、描述                       | 数据隔离容器                                            |
| 项目信息 → 临时用房 | 临时用房资源、安全系数、每间人数 | 优化/估算时按峰值人数推算**临时用房间数**与**用房碳排** |
| 项目信息 → 施工计划 | 计划/实际开竣工日期              | **折现锚点**（PV 计算的第 0 天）                        |
| 项目信息 → 施工计划 | 施工碳排放限额                   | ⚠ 仅参考记录，**不参与任何计算**                        |

### 2. 阶段 1：计划阶段（先建模，再优化，后定基线）

**1.1 任务管理**（nav 任务管理）

- 做什么：建工序（名称、工期≥0.5、完成度 0~1）、设前置依赖（FS/SS/FF/SF）
- 输入 → 影响：工期与依赖 → CPM 实时计算 → 甘特图关键路径（红）、进度统计总工期/关键路径工期
- 怎么调输出：压缩**关键路径上的工序**才能缩短总工期；非关键工序压缩不影响总工期
- （v1.1：lag 已移除，需要滞后时用过渡任务模拟）

**1.2 资源管理**（设置 → 资源管理）

- 做什么：定义资源（类别、单价、碳因子）+ 从公共资源批量拷贝 + 打标签
- 输入 → 影响：
  - **类别**决定施工模式乘子的作用范围（机械/人工随模式变化，材料/运输不变）→ 类别填错直接扭曲优化结果
  - 单价 → 成本；碳因子 → 碳排
- 怎么调输出：碳因子/单价是成本碳排的"基准"，改它们 = 全局改口径

**1.3 资源使用录入**（nav 资源使用录入，录入 Tab）

- 做什么：按（日期 × 工序 × 资源 × 用量 × 类型）批量录 PLANNED / ACTUAL
- 输入 → 影响：这是**优化与基线计算的唯一用量数据源**（唯一约束：同项目/工序/日/资源/类型一条）
- 怎么调输出：录 PLANNED → 优化时选"PLANNED 口径"；录 ACTUAL → 实际侧口径

**1.4 设置**（三个子页）

- 资源限制：资源日用量上限 → 优化时剔除超限方案（⚠ 前提：标准方案本身不能超限，否则无解）
- 材料复用：周转次数 → 折减碳因子（可选折减单价）→ 影响优化、月度报表、图表、基线
- 优化配置：NSGA2 默认参数（种群/代数/IRR/加速比例/最大偏移）→ 每次新建运行的默认值

**1.5 优化结果**（分析洞察 → 优化结果）

- 做什么：配置参数（可覆盖项目默认）→ 开始优化 → 后台异步跑 → 轮询进度 → 帕累托前沿（3D 散点 + 解集表格）
- 输入 → 影响与**调参旋钮**：

| 参数                    | 影响                               | 调整方向                            |
| ----------------------- | ---------------------------------- | ----------------------------------- |
| 种群/代数               | 解的质量与覆盖度                   | 解少/前沿不完整 → 调大；太慢 → 调小 |
| IRR（名义年利率）       | 成本现值目标 f1                    | 按企业资金成本设置                  |
| 加速工期比例            | 模式 1/3 的工期缩放与成本          | 按实际赶工能力（0.5~1.0）           |
| 最大偏移天数            | 开始时间可延后上限（资源均衡能力） | 要压资源峰值 → 调大                 |
| 用量类型 ACTUAL/PLANNED | 用哪套用量算成本/碳排              | 与数据准备一致                      |
| 资源限制                | 可行域                             | 约束过严 → 无解提示                 |

**1.6 计划编制**（分析洞察 → 计划编制）——**主线的关键闭环点**

- 做什么：选运行 + 选解 → 添加减碳措施 → 预估 → 保存为**计划基线**（或草稿）
- 输入 → 影响：
  - 方案来源（run + solution）→ 基线排程、总工期/成本/碳排、月度分布
  - 减碳措施：
    - **ADD**：加负碳因子资源（如光伏）→ 预估节碳
    - **REPLACE**：计划资源 → 实际资源替换 → 预估节碳
  - 保存基线 → 评价阶段的对照基准 + 月度报表的 PLANNED 口径来源
- 怎么调输出：改措施、换解、重新预估 → 重新保存基线

### 3. 阶段 2：施工阶段（执行与记录）

**2.1 日报处理**（nav 日报处理，5 步向导）

- 做什么：导入 → 核对资源（精确匹配/新建/跳过）→ 分配到工序 → 确认提交 → 完成
- 输入 → 影响：每天的实际用量 → 落 `task_resource_usage`（**恒为 ACTUAL**）；运输类自动打"货物类别"标签；提交时可附带当日工序进度
- ⚠ 提交不可逆；重复导入有风险（见第二部分 A-2）

**2.2 资源使用录入**（历史/统计 Tab）

- 历史：查询/编辑/删除已录用量、补打用量标签（运输漏标的兜底）
- 统计：所选资源随时间的用量/排放曲线（ACTUAL/PLANNED 分别或合并）

**2.3 施工进度**（分析洞察 → 施工进度）

- 做什么：按日录入工序进度（append-only）、录天气（月降水/气温/日照）、看全景甘特 + 月度碳排/成本
- 输入 → 影响：进度 → 回写 `task.completed`、推导工序实际起止日期 → 影响践行度的实际侧与评价解锁（项目完成后解锁）

### 4. 阶段 3：评价阶段（复盘）

**3.1 碳排放分布**：按「设置 → 碳排放图表」定义的标签切片看饼图（碳排放/成本双口径、日期/类型过滤）
**3.2 计划践行度**：基线 vs 实际——总工期/总成本/总碳排、逐工序对照、材料用量差异、逐月对照
**3.3 低碳措施**：每条措施的预估节碳 vs 实际节碳（按状态 计划中/已实施/未实施）

### 5. 输入 → 输出影响总矩阵

| 输入数据                   | 影响范围                                                 |
| -------------------------- | -------------------------------------------------------- |
| 任务工期                   | 甘特、CPM 总工期、优化目标 f3、基线快照                  |
| 依赖类型                   | CPM、优化 f3、基线排程（v1.1：lag 已移除，三处口径一致） |
| 资源类别                   | 施工模式乘子的作用范围（机械/人工受影响，材料/运输不受） |
| 资源单价                   | 成本 f1、月度成本、践行度计划/实际成本                   |
| 资源碳因子                 | 碳排 f2、月度排放、图表、措施节碳、践行度                |
| 用量记录（ACTUAL/PLANNED） | 全部成本/碳排计算、优化约束判定、峰值人数                |
| 资源限制（日上限）         | 优化可行域（⚠ 仅对已配置资源、按平均摊日判定）           |
| 周转配置                   | 有效碳因子/单价 → 优化、月度、图表、基线                 |
| IRR                        | 成本现值 f1、基线 PV、践行度计划成本                     |
| 加速比例                   | 模式 1/3 的工期与成本                                    |
| 最大偏移天数               | 决策空间大小、资源均衡能力                               |
| 减碳措施                   | 基线预估指标、措施页节碳对比                             |
| 工序进度                   | `task.completed`、实际起止日期、评价解锁                 |
| 天气                       | ⚠ 无（仅展示）                                           |
| 碳限额                     | ⚠ 无（仅参考记录）                                       |
| 省市区/建筑概况            | ⚠ 无（仅信息记录与下拉校验）                             |
