# 总纲

该软件能够有某种方式获取施工中的数据（包括工序信息、工序的资源使用情况），从而为施工策略提供一些参考。所谓的施工策略，是用户定义的一系列施工模式，定义了从标准策略转变为该模式时，工序成本、工期、碳排放三者之间的关系。当工序的施工模式发生变化时，整个项目的成本、工期、碳排放会发生变化，可能变化数为各工序的可能模式的乘积。用户要求使用 nsga2 算法进行多目标的优化，并在前端进行帕累托解集的可视化。

# 数据流

### 预设数据

1. 资源分类（分类名称，父分类）
2. 资源信息（资源名称，所属分类，资源单价，资源碳排放因子）

### 输入数据

1. 工序信息（名称，唯一代号，描述，预计工期）
2. 工序完成度（工序，月份，完成百分比）
3. 工序资源使用（工序，日期，资源，使用量）

### 计算参数（输入）

- NSGA-II 参数（种群数量，，交叉率，变异率）
- 利率
- 碳交易中的碳单价

### 整合数据

1. 各工序的资源使用量
2. 各工序的碳排放
3. 各工序的成本
4. 各工序的实际工期

### 优化结果输出

- 帕累托解集
- 各个解的关键路径

# 决策与细节

## 数据提交与目标不符合问题

### 问题

- 各类数据时间粒度不一致。工序的资源使用情况按日输入，工序的完成进度百分比按月输入
- 现有数据与预测数据不一致。现有的数据总是为部分数据（施工现场输入时工序不太可能完成），而针对施工模式的优化是面向未来或者反思过去的。

## 使用施工日报

### 施工日报的问题

- 日报中各项资源使用情况都是汇总的，未与具体工序相绑定
- 日报中很有可能因为某些人为原因出现不合适的资源类型等

### 解决方案

设计一个页面，该页面能够为某天某项工序添加一系列资源使用情况。导入的施工日报经过解析，找到可能的资源并呈现给前端，并提供修改的操作。

设计一个日报提交页面，该页面的原始提交方式为通过表单填写，为工序添加当日资源使用信息。当用户选择导入一个施工日报时，应用程序完成施工日报的解析，并给出解析结果。解析结果需要以表单的形式给出以方便修正，类似于下表的结构（资源名称与数量可编辑）：

| _**人员使用情况**_ |             |        |      |
| ------------------ | ----------- | ------ | ---- |
| **工种**           | 木工        | 钢筋工 | 泥工 |
| **数量**           | 3           | 4      | 7    |
| **工种**           | ACL         |        |      |
| **数量**           | 5           |        |      |
| ---                |             |        |      |
| _**机械使用情况**_ |             |        |      |
| **型号**           | 挖掘机 A 型 |        |      |
| **数量**           | 12          |        |      |

由用户核对资源名称与数量与实际相符。随后，进入分配模式，即将资源的使用分配给各个工序。类似于下面的结构：

```html
<select lable="progress"></select>
<div>
  <div>{{ 资源名称 }}</div>
  <input type="slide" max="解析结果" />
  <div>{{ 该工序该资源使用情况 }}</div>
</div>
```

分配完成后，向后端发送 JSON 数据。

```mermaid
graph LR;
A("用户上传 excel 文件并解析")
B("修正解析后的数据")
C("分配到工序并上传")
A --> B --> C;
```

## 考虑并行施工

### 问题

- 最后的总时间并非各个工序的工期之和，而是关键路径的工期之和
- 进行优化的过程中，个别工序的工序发生假设中的变化时会影响关键路径
- 考虑资源的约束

### 解决思路

- 使用关键路径法，计算各个工序的 _最早开始时间_、_最早完成时间_、_最晚开始时间_、_最晚结束时间_ 等，以获取关键路径以及总工期（事实上，如果只需总工期而不需要关键路径，则无需计算最晚开始时间和最晚结束时间）
- 每次取样都重新使用关键路径法来计算时间这个目标函数
- **不考虑**资源的约束，理由如下：当工序的划分比较大时，即使考虑资源的约束，得到的也只是一个过程中的平均值，**不具备**太多参考意义
